SOP：穿搭智造局

SOP：穿搭智造局-首次使用与核心功能操作指南

一、适用场景

  1. 新用户首次使用穿搭智造局，需要完成账号设置并体验核心功能
  2. 运营人员需要生成穿搭内容、管理商品SKU或查看VOC周报
  3. 内部测试/演示时需要快速了解产品全流程

二、适用对象

  • C端普通用户：有日常穿搭需求的女性用户（18-40岁）
  • B端运营人员：服装账号新媒体运营、服装产品运营、穿搭博主

三、流程目标

  • C端用户：10分钟内完成首次建档并体验三大核心功能（查尺码/看灵感/查避雷）
  • B端运营人员：30分钟内完成登录、尺码表上传、话术生成、VOC周报查看

四、所需工具／材料

  • C端用户
  1. 智能手机或电脑，安装Chrome/Edge/Safari浏览器
  2. 稳定的网络连接
  3. 皮尺（如需精确测量三围数据）
  4. 已有衣物清单（如需快速搭建衣橱）
  • B端运营人
  1. 电脑，安装Chrome/Edge浏览器
  2. 品牌合作清单（如需批量添加品牌）
  3. Excel格式的尺码表（如需批量导入尺码数据）
  4. Excel格式的SKU清单（如需批量导入商品数据）
  5. 商品白底图（如需测试内容生成功能）

五、操作步骤

第一阶段：访问与身份选择

  • 步骤1：访问网站
  1. 操作内容：打开浏览器，输入网站地址：https://asdf951-f.github.io/Outfit/
  2. 预期结果：页面加载，显示入口判定页
  3. 完成标准：看到“穿搭智造局”品牌标识和两个入口卡片（普通用户 / 运营者）
  • 步骤2：选择身份
  1. 操作内容：根据自身角色点击对应入口卡片
  2. 普通用户 → 点击「普通用户」→ 进入新用户导览
  3. 运营人员 → 点击「运营者」→ 进入运营登录页
  4. 完成标准：跳转到对应的下一个页面（新用户导览 或 运营登录页）

第二阶段：C端用户路径

  • 步骤3：完成新用户导览（3步建档）

操作内容：

  1. Step 1 选体型：点击选择5个体型之一（H型/梨形/苹果形/沙漏形/倒三角）如不确定，点击「帮我判断」输入胸围/腰围/臀围 → AI自动判断。
  2. Step 2 输入身高体重：拖拽滑块输入身高和体重，选择偏好（修身/合身/宽松）
  3. Step 3 极速衣橱：勾选已有的衣物品类（如白色T恤/牛仔裤等），选择风格偏好（多选）和肤色
  4. 完成标准：点击「完成建档」→ 跳转到首页，顶部显示用户昵称

补充说明：网站已预设示例用户（小雨）用于演示，用户进入页面后可看到示例数据和穿搭推荐效果，帮助快速理解产品功能。用户可跳过建档直接浏览，或在个人中心替换为自己的数据。

  • 步骤4：体验三大核心功能

4.1 查尺码（精准尺码指南）

  1. 点击「精准尺码指南」入口卡片 → 确认身高/体重/体型/偏好/面料 → 点击「生成推荐」
  2. 看到五维矢量模特 + 推荐衣长/裤长/裙长 + 面料适配建议
  3. 完成标准：看到具体的衣长数值和身体位置标注

4.2 看灵感（AI灵感库）

  1. 点击「AI灵感库」入口卡片 → 查看今日3套推荐穿搭 → 点击单品查看详情
  2. 点击❤️收藏喜欢的穿搭方案 → 点击「换一批」刷新推荐
  3. 完成标准：成功收藏至少1套穿搭方案

4.3 查避雷（真实体验中心）

  1. 点击「真实体验中心」入口卡片 → 查看避雷排行榜 → 使用三维筛选器按体型/品类/尺码筛选
  2. 点击「我也要吐槽」→ 填写表单（品牌/品类/尺码/避雷类型/描述）→ 提交
  3. 完成标准：成功提交1条吐槽，看到“发表成功”提示

第三阶段：B端运营路径

  • 步骤5：运营登录/注册

操作内容：

  1. 已有账号：输入账号/手机号/邮箱 + 密码 → 点击「登录」
  2. 无账号：点击「没有账号？去注册」→ 填写手机号/邮箱 + 设置密码 + 确认密码 → 点击「立即注册」
  3. 除演示账号 admin/admin123 外，运营人员可使用自己的手机号或邮箱注册登录，数据通过 operator_id 自动隔离
  4. 预期结果：登录/注册成功，自动跳转运营后台（dashboard.html）
  5. 完成标准：看到运营后台数据看板页面，右上角显示运营账号名称
  • 步骤6：查看数据看板

操作内容：

  1. 查看KPI卡片（AI生成穿搭方案数/尺码表数/SKU管理数/VOC吐槽数）
  2. 点击时间筛选（今日/本周/本月）切换数据范围
  3. 切换到第二个Tab「闭环工作台」→ 查看C端行为数据卡片和AI洞察
  4. 完成标准：所有KPI卡片显示数据（非0），闭环工作台展示4条AI洞察
  • 步骤7：尺码表管理

操作内容：

  1. 进入「尺码表管理」→ 填写商品名称/品类/面料/目标客群体型
  2. 方式A：手动输入尺码表数据（S/M/L各码的胸围/腰围/衣长等）
  3. 方式B：点击「Excel导入」→ 上传.xlsx/.csv文件 → 数据预览
  4. 点击「生成卖点话术」→ 等待AI生成4-5条话术
  5. 点击「复制」使用话术
  6. 完成标准：成功生成至少4条话术，点击复制后粘贴成功
  • 步骤8：内容生成

操作内容：

  1. 进入「内容生成」→ 上传3张白底图（点击/拖拽）
  2. 选择目标客群体型和风格方向 → 点击「一键生成」
  3. 查看生成的穿搭海报和小红书标题 → 点击「发布」
  4. 完成标准：发布成功，提示“已发布到C端灵感库”
  • 步骤9：VOC周报

操作内容：

  1. 进入「VOC周报」→ 查看周报概览（新增吐槽数/问题分级统计）
  2. 查看关键词云（高频吐槽词按大小排列）
  3. 查看优先级分级（高/中/低三级问题 + 行动建议）
  4. 点击「导出周报」下载Excel文件
  5. 完成标准：周报显示数据，至少看到1条高/中优先级问题

第四阶段：个人中心管理（C端）

  • 步骤10：编辑个人档案

操作内容：

  1. 点击右上角头像 → 进入「个人中心」
  2. 点击「编辑资料」→ 修改昵称/身高/体重/体型/风格偏好/肤色
  3. 点击「帮我判断」可重新测量体型
  4. 点击「保存修改」
  5. 完成标准：修改后返回产品文档，看到更新后的用户信息
  • 步骤11：管理衣橱和收藏

操作内容：

  1. 点击「我的衣橱」→ 极速模式（勾选品类）/ 精细模式（拍照上传）
  2. 点击「我的收藏」→ 查看已收藏的穿搭方案和单品
  3. 可取消收藏
  4. 完成标准：衣橱显示已录入的单品数量，收藏列表显示已收藏的方案

七、注意事项

1. C端数据不上传：身高/体重/体型/衣橱/收藏等所有数据仅存储在浏览器本地（localStorage），清除浏览器缓存会导致数据丢失，建议定期使用“导出数据”功能备份

2. 密码安全：B端运营账号密码使用bcrypt加密存储，如忘记密码需联系管理员重置

3. Token自动续期：B端登录后Token有效期为24小时，剩余<2小时自动刷新，用户无需手动操作

4. AI功能依赖API Key：卖点话术生成、标题生成、VOC周报生成依赖QWEN_API_KEY环境变量，如未配置将返回模拟数据

5. 分页加载：灵感库单品每页24件，搭配每页12套，滚动到底部自动加载更多

6. 图片上传限制：白底图单张不超过5MB，支持JPG/PNG格式

7. 验证码已移除：MVP阶段B端注册已移除验证码，直接使用手机号/邮箱+密码注册

8. 隐私承诺：C端数据仅存本地，不上传服务器

9. 当前环境说明：当前为开发测试环境，产品仍在微调和迭代中，部分功能可能持续优化

10. 预设示例用户：网站已预设示例用户数据用于演示，用户可直接查看效果，也可替换为自己的数据

11. 运营账号注册：除演示账号 admin/admin123 外，运营人员可使用自己的手机号或邮箱注册登录

十、完成标准

  2. 已生成至少1次尺码推荐，看到衣长/裤长/裙长数据
  3. 已收藏至少1套穿搭方案
  4. 已成功提交1条吐槽
  5. 数据保存后刷新页面仍可见
  • B端运营完成标准
  1. 已成功登录运营后台，看到数据看板
  2. 已成功上传尺码表并生成至少4条话术
  3. 已成功发布内容到C端灵感库
  4. 已成功生成VOC周报，看到关键词云和优先级分级
